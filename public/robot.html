🚀 Robot Franky — terbang dengan roket

Robot berjas dari GIF kamu, digambar ulang dengan kode tiap frame — bukan file gambar. Sekarang dia terbang melintas kota neon dengan roket di kedua sepatunya: api menyala, asap knalpot mengepul, dan dia berbalik arah di ujung panggung. Ketuk panggungnya untuk melesat naik.

Cara pasang di web Franky Bot

Ini versi terbang: robot melintas panggung kiri-kanan dengan roket di kedua sepatu, lengkap dengan api, asap knalpot, dan garis angin. File ini sudah jadi satu halaman mandiri, tanpa file luar. Upload file ini ke folder public di repo GitHub franky-bot, lalu buka:

https://franky-bot.vercel.app/robot.html

Robotnya sudah dipasang sebagai hero di dashboard (index.html) lewat iframe ini:

<iframe src="/robot.html" style="width:100%;height:520px;border:0;border-radius:16px;" title="Robot Franky"></iframe>

Semua animasi jalan otomatis saat halaman dibuka; tidak ada gambar yang perlu di-upload.
