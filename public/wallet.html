Buat Wallet Bot Franky

Membuat 2 wallet khusus bot: 1 Solana + 1 EVM (dipakai bareng untuk BNB, Base, dan HyperEVM).

Privasi: wallet dibuat di HP kamu, di halaman ini saja. Private key tidak pernah dikirim ke server mana pun — tidak ke Vercel, tidak ke Harbor, tidak ke siapa pun.
Simpan baik-baik. Siapa pun yang memegang private key bisa mengambil semua dana di wallet itu. Simpan di password manager / catatan aman. Kalau key hilang, dana tidak bisa diambil kembali.

Wallet Solana

Alamat (kirim SOL ke sini)
Private key (base58) — isi ke Vercel sebagai SOLANA_PRIVATE_KEY

Wallet EVM (BNB + Base + HyperEVM)

Alamat (sama untuk semua chain EVM)
Private key (0x…) — isi ke Vercel sebagai EVM_PRIVATE_KEY

Setelah wallet dibuat

  1. Simpan kedua private key di tempat aman.
  2. Di dashboard Vercel → franky-bot → Settings → Environment Variables, isi SOLANA_PRIVATE_KEY dan EVM_PRIVATE_KEY (tempel nilai dari atas, jangan kirim lewat chat).
  3. Danai kecil dulu:
    • SOL → alamat Solana
    • BNB → alamat EVM (jaringan BSC)
    • ETH → alamat EVM (jaringan Base)
    • HYPE → alamat EVM (jaringan HyperEVM)
  4. Terakhir, ubah DRY_RUN jadi false di Vercel, lalu redeploy. Kabari Harbor alamat + jumlah dananya supaya dicek dulu saldonya.
